## Projetos em destaque

### [Detecção Automática de EPIs](https://github.com/Bryan9895/detector-de-EPIs)
Projeto de Iniciação Científica **PIBIC Jr. 2026** para desenvolver um sistema capaz de detectar automaticamente Equipamentos de Proteção Individual em imagens e vídeos utilizando **Python, YOLO11 e OpenCV**.

### [VolantePDI](https://github.com/Bryan9895/VolantePDI)
Controlador para jogos de corrida utilizando **visão computacional e reconhecimento de gestos**. O projeto usa webcam, MediaPipe Hands e Python para transformar os movimentos das mãos em comandos do jogo.

### [Monitor de Sistemas](https://github.com/Bryan9895/Monitor-de-sistemas)
Aplicação voltada ao monitoramento de informações de hardware em tempo real, como utilização de CPU, memória, temperatura e outros indicadores de desempenho.
